# Security Policy

## Reporting a Security Vulnerability

We take security seriously. If you discover a vulnerability or security issue, please do not disclose it publicly. Instead, report it through the following channel:

1. Send an email to **varunkulkarninagpur@gmail.com** detailing the vulnerability.
2. Include steps to reproduce the issue, along with any relevant context (OS, VS Code version, example files).
3. We will acknowledge your report within 48 hours and work on a fix.
4. A security patch or release will be published as soon as the issue is resolved.
